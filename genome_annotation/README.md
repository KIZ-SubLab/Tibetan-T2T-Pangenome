# Genome annotation

These workflows characterize telomeres and centromeres in the phased Tibetan assemblies for Figure 2 and support downstream analyses of candidate centromeric introgression.

| Workflow | Analysis |
| --- | --- |
| [Telomeres](telomere/) | Telomere detection, architecture classification, telomeric variant repeats, and subtelomeric TAR1 elements. |
| [Centromeres](centromere/) | Centromeric satellites, alpha-satellite higher-order repeats, comparison with APGp1, and centromeric introgression. |
