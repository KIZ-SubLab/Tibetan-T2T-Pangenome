# Archaic introgression

These workflows detect candidate archaic ancestry and characterize introgressed haplotypes, structural variants, and local genealogies.

| Workflow | Analysis |
| --- | --- |
| [Archaic segment detection](segments/) | SPrime, HMM and hmmix analyses, consensus overlap filtering, and TRACE job orchestration. |
| [Archaic SV genotyping](archaic_sv_genotyping/) | CHM13-based preparation of structural variant inputs for Paragraph genotyping. |
| [Introgression statistics](fd/) | Window and region estimates of f_D, result validation, and visualization. |
| [SV haplotype heatmaps](heatmap/) | Haplotype comparisons, summaries, and heatmaps. |
| [Extended haplotype homozygosity](ehh/) | LD proxy selection, phase clustering, and EHH visualization. |
| [Locus plots](locuszoom_daf/) | Integrated views of PBS, archaic f_D, derived allele frequencies, and regulatory tracks. |
| [Relate and CLUES2](relate/) | Local genealogies and allele frequency trajectories. |
| [MSMC2](msmc2/) | Coordinate conversion, callable masks, model fitting, decoding, and local TMRCA plots. |
